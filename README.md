# Mob Highlight

给半径内的生物套一层原版发光描边——光灵箭那种效果，隔着方块也看得见——按规则着色。
支持其他模组添加的生物，带图形配置界面。

描边走的是原版 outline 管线，贴合实体模型本身，不是碰撞箱那种方框。

纯客户端，不用 Mixin，服务端不需要装任何东西。

**需要**：Minecraft 1.21.11 · Fabric Loader 0.18.4 或更高 · Fabric API

## 安装

把 `mobhighlight-<版本>.jar` 和 Fabric API 一起放进 `mods/` 目录。

换版本之前记得先删掉旧的 `mobhighlight-*.jar` —— 两个同 id 的 jar 会让加载器直接中断启动。

## 按键

| 按键 | 作用 |
| --- | --- |
| `H` | 开关，聊天栏会提示已开启 / 已关闭 |
| `J` | 打开配置界面 |
| `]` / `[` | 探测半径 ±8 格 |

按键可以在配置界面「常规」页跳到原版控制设置里改。

> 有人问为什么不做成 Ctrl+H：1.21.11 的 `KeyMapping` 只存单个按键、不存修饰键，按 Ctrl+H 时绑在 H 上的功能一样会被触发，两者分不开。

## 配置界面

五个页签：

- **常规** —— 总开关、穿墙显示、隐身处理、给自己描边、半径、单帧上限、分类校正间隔、改按键
- **默认规则** —— 七个自动归类分类（玩家 / 友好 / 中立 / 敌对 / 水生 / 环境 / 其他），每类一行开关加一个色块
- **自定义规则** —— 自己挑实体、起名配色，见下节
- **实体清单** —— 列出所有实体含模组生物，支持搜索和按模组筛选，每行三态循环：跟随规则 / 强制发光 / 永不发光
- **模组来源** —— 按模组整体开关，某个模组出兼容问题时用这个快速关掉

穿墙显示默认开着，也就是原版发光的样子，零额外开销。关掉之后只给视线内的生物描边，每帧会多出射线检测。

界面上改任何东西都会立刻写进 `config/mobhighlight.json`。

## 关于规则

默认规则按标签和注册类别自动归类，不依赖任何硬编码的生物名单，所以模组生物也能自动落到合适的分类里。

自动分不准的可以自己建规则捞出来。典型例子是村民：它的注册类别是 MISC，又没有分类标签，默认规则只能把它归到「其他」。点「添加实体」先看到分类列表，进分类后再挑具体实体，加进去的实体就改用这条规则的颜色。

已经被别的规则挑走的实体会变灰、点不动，想挪就先从原来那条里移出来。删掉实体或整条规则，它会立刻回到默认规则的分类和颜色。

## 命令

```
/mobhl                      打开配置界面
/mobhl toggle               总开关
/mobhl radius [blocks]      查看 / 设置半径（4~128）
/mobhl max <count>          单帧最多描边数量
/mobhl scan <millis>        分类校正扫描间隔
/mobhl rule <id>            切换某个默认规则分类的开关
/mobhl reload               重新读取配置文件
/mobhl reset                恢复默认
/mobhl status               打印当前配置摘要
```

## 已知问题

1. 有些模组注册的实体渲染器没有提供 outline 变体，这种情况下渲染会抛
   `Can't render an outline for this rendertype!`，游戏可能崩溃。原版发光有同样的限制，
   只是这个模组同时标记的实体更多、更容易碰到。遇到时到日志里搜这行，然后去「模组来源」页
   把那个模组关掉。
2. 区分不出自己和别的玩家，默认按「距离相机不到 1 格」判断为自身并跳过。要给自己也描边，
   把配置里的 `glowSelf` 打开。

## 构建

需要 JDK 21 与 Gradle 9.x（Loom 1.17 要求 Gradle 9 以上）。项目根目录执行：

```bash
gradle build
```

产物在 `build/libs/`，文件名里的版本号取自 `gradle.properties` 的 `mod_version`。
